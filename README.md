# Schrank CAD

Cabinet planning with 2D and 3D views, parts lists, Excel export and CNC / woodWOP.

**Developer:** Povilas Grusauskas  
**Website:** https://schrankcad.ch  
**Contact:** info@schrankcad.ch

## Windows download

[Download the latest Windows release](https://github.com/grusauskaspovilas-code/SchrankCAD-Releases/releases/latest)

Choose the `SchrankCAD-Setup-...-windows-x64.exe` file under **Assets**. Supports Windows 10/11 x64. A GitHub account is not required to download it.

## Access

To use Schrank CAD you need an account approved by the developer. Sign in with your approved email and the one-time code sent to it. A valid signed license allows up to 30 days of offline work, limited by account expiry.

Save cabinet projects before installing updates. The Windows app checks new releases and verifies the installer SHA-256 digest before installation.

This repository contains distribution files and release information. Application source is maintained separately.
